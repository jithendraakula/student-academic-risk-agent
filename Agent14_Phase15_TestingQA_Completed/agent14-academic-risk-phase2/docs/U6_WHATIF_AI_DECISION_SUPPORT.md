# U6 — What-If + AI Decision Support

The Mentor What-If tool is a guided one-factor academic scenario simulator. It never persists a scenario.

Flow:
1. choose one measurable factor
2. review the current value
3. use a recommended target or enter a target
4. compare estimated risk/priority before and after
5. optionally ask the configured AI provider for an explanation

Assignment completion is never silently converted into assessment participation. Course simulation changes one selected course factor only.

AI is optional. The numerical simulation remains independent of the external LLM provider.
