# U3 — Mentor Dashboard Workflow

The mentor workspace is operationally ordered as:

1. Today's attention summary.
2. Students requiring a decision.
3. Student case review.
4. Support action/intervention.

Student KPIs remain unique-student metrics. Open case work is explicitly presented as work items and may exceed the number of students represented.

The queue uses the canonical backend `risk_level` rather than recreating a different severity mapping from `risk_score`.

Faculty-facing student identifiers use the authoritative CSE roll number when available.
