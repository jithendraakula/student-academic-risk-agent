# U2 — Institutional Design System

U2 establishes a shared visual foundation for Agent 14 using the supplied Vignan's University reference as the visual authority.

## Locked visual language
- White institutional surfaces with deep academic navy/blue.
- Pale blue support surfaces for primary workflow emphasis.
- Neutral slate text and borders for structure.
- Green/amber/orange/red reserved for semantic status and risk.
- No decorative AI-first color treatment.

## Shared primitives
`AcademicUI.tsx` provides reusable section headings, status chips, buttons, icons, metric cards, and key/value blocks.

Global CSS tokens standardize spacing, control heights, borders, focus treatment, typography hierarchy, and card surfaces.

The goal is to make all faculty workflows feel like one university application instead of unrelated dashboard pages.
